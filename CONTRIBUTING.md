# Как участвовать в разработке (Contributing Guide)

Спасибо за интерес к развитию **Zapusk**! Чтобы проект оставался чистым и удобным для всех, придерживайтесь нескольких простых правил.

## Окружение и запуск

Проект использует менеджер пакетов **`uv`** и стандартный **`Makefile`** для сборки.

1. **Установка зависимостей и запуск из исходников:**
   ```bash
   uv sync
   uv run python -m zapusk gui
   ```

2. **Сборка бинарного файла (через Nuitka):**
   ```bash
   make standalone   # Быстрая сборка в ./build для проверки
   make              # Финальная сборка в один файл ./build/zapusk
   ```

3. **Локальная установка в систему (без `sudo`):**
   ```bash
   make install      # Установит бинарник в ~/.local/bin и ярлык в меню
   make uninstall    # Удалит приложение и ярлык из системы
   ```

## Правила работы с Git

* **Никаких артефактов сборки в репозитории.** Папки `build/`, `dist/`, `__pycache__/`, `.venv/` и скомпилированные бинарники не должны попадать в коммиты (они уже добавлены в `.gitignore`).
* **Атомарные коммиты.** Делайте один коммит под одну конкретную задачу, а не один огромный коммит на весь релиз.
* **Формат сообщений (Conventional Commits):**
  * `feat: ...` — новая функциональность
  * `fix: ...` — исправление бага
  * `refactor: ...` — улучшение структуры кода без изменения поведения
  * `docs: ...` — обновление документации (`README.md` и др.)
  * `chore: ...` — обновление `.gitignore`, зависимостей, `Makefile`

## Структура проекта

* `src/zapusk/core/` — основная логика (работа с Wine/Proton, парсинг образов, импорт игр). Не смешивайте её с кодом интерфейса.
* `src/zapusk/gui.py` — графический интерфейс на PySide6.
* `src/zapusk/cli.py` — консольный интерфейс.
* `assets/` — иконки и `.desktop`-файл.
