# 🎮 ZAPUSK — запускай любые Windows-игры на Arch Linux в один клик

**Скачал → запустил → перетащил .exe → играешь.** Никаких консолей, никакой магии с префиксами.

Zapusk — это лаунчер, который **сам** ставит весь нужный стек (Wine, DXVK, VKD3D-Proton,
Vulkan-драйверы, gamemode) и **сам** настраивает каждую игру: зависимости Windows
(vcrun, d3dx9, dotnet, шрифты), версию Windows, оптимизации. Тебе нужно только указать .exe.

## 🚀 Как пользоваться (совсем просто)

```bash
# 1. Распакуй и запусти
cd zapusk
python -m zapusk gui
```

Дальше всё в окне:

1. **⚙️ Установка → «🔧 Установить всё автоматически»** — один раз, введи пароль.
   После этого **перезагрузи компьютер** (нужно для Vulkan).
2. **Перетащи .exe или папку с игрой прямо в окно** (drag & drop).
3. Нажми **«🚀 Починить и запустить»** на карточке игры.
   Первый раз ставит зависимости (10–20 минут) — потом игра запускается мгновенно.

Готово. Играй.

Всё это работает: репаки, лицензионные установщики, GOG-версии. Для GTA 5 выбери пресет **gta5** — он ставит всё для Rockstar Social Club.

## 📦 Что ставит кнопка «Установить всё»

| Компонент | Зачем |
|---|---|
| `wine-staging` | запуск .exe (свежий, с fsync/esync) |
| `dxvk` | DirectX 9/10/11 → Vulkan (прирост FPS огромный) |
| `vkd3d-proton` | DirectX 12 → Vulkan |
| `lib32-*` драйверы | **без них игры молча не стартуют** — самая частая проблема |
| `gamemode`, `mangohud` | производительность и оверлей FPS |

## 🔧 Если игра не стартует

1. Страница **⚙️ Установка → «🔎 Проверить систему»** — все пункты должны быть ✅.
2. Страница **📋 Логи** — выбери игру, читай последние строки, ищи `err:`.
3. В настройках игры (⚙ на карточке) попробуй: выключить Fsync, включить «Виртуальный рабочий стол», сменить пресет.
4. Скинь лог сюда (GitHub Issues) — разберёмся.

## ⚠️ Честно

- Античит-онлайн (Vanguard, EAC без линукс-поддержки) — **не** заработает нигде вне официального Steam. Одиночные режимы — работают.
- Zapusk не новый транслятор — это правильно собранный и автоматизированный стандартный стек
  (Wine + DXVK + VKD3D). Именно поэтому оно реально работает.

## 📦 Установка как приложение (иконка в меню)

```bash
./install_app.sh        # в ~/.local: иконка + пункт меню, без root
```
Или нативный пакет Arch: положи zapusk в `~/zapusk`, собери `makepkg -si` (PKGBUILD в комплекте) — получишь `zapusk` в /usr/bin.

Или один бинарник: `pip install pyinstaller && pyinstaller zapusk.spec` → `dist/zapusk`.

## 🐧 FreeBSD и прочие системы — честно

Zapusk ставит на FreeBSD `wine-devel` + `winetricks` через pkg и скачивает DXVK сам. **Но:**
- DXVK/VKD3D под FreeBSD работают частично (эксперимент), тяжёлые DX12-игры могут не пойти
- Steam, античиты, Vanguard — не работают в принципе
- Minecraft — это Java: используй пресет `java` (нативный запуск, Wine не нужен)

Логи всегда в 📋 — если игра не стартует, присылай последние строки.
## 🎮 FreeBSD Gaming Mode (bhyve + GPU passthrough)

Запуск **тяжёлых и онлайн-игр** на FreeBSD с ~100% скоростью GPU: Linux-VM (Zen kernel)
получает твою настоящую видеокарту через PCIe passthrough, а Looking Glass показывает
картинку игры в окне на FreeBSD-десктопе.

```sh
sudo sh scripts/freebsd_gaming_mode.sh
```

Скрипт проверяет IOMMU (VT-d/AMD-Vi), находит GPU, настраивает `pptdevs`, создаёт
ZFS-zvol и генерирует готовый скрипт запуска bhyve с IVSHMEM-регионом для Looking Glass.

**Требования:** FreeBSD 14+, CPU с VT-d/AMD-Vi (включить в BIOS), карта для VM
**плюс любой вывод для хоста** (iGPU или дешёвая карта). Почти все античиты в VM
работают; Vanguard (Valorant) сознательно блокирует VM.

**Статус:** на реальном железе не тестировано — первый тестер это ты. Логи → GitHub Issues.
