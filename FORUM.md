# 💬 Как включить форум (2 минуты, один раз)

1. На github.com/romanepev2014-stack/zapusk → **Settings** → раздел **Features** → поставь галочку **Discussions** → Save
2. Открой **giscus.app** → в поле repository введи `romanepev2014-stack/zapusk` → жми загрузить
3. Скопируй из сгенерированного кода значения `data-repo-id` и `data-category-id`
4. В `site/index.html` замени `ВСТАВЬ_REPO_ID` и `ВСТАВЬ_CATEGORY_ID` на эти значения
5. Закоммить, запушь — форум живой в разделе «Сообщество» на сайте

Форум живёт в GitHub Discussions: бесплатно, модерация через GitHub, история навсегда.
